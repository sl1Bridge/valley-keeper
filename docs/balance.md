| Враг | HP | Атака | Защита | Скорость | Опыт | Появляется |

| Правило | Значение |
|---|---|
| Волн в локации | 20 (`TOTAL_WAVES`) |
| Размер волны | min(2 + N, 5) врагов (`MAX_ENEMIES`) |
| Веса типов (слизень / волк / голем) | max(1, 7−N) / min(max(N−1, 0), 4) / min(max(N−3, 0), 4) (`type_weights`) |
| Множитель HP/атаки | 1 + 0.10 × (волна−1) + 0.25 × победы |
| Множитель защиты | 1 + 0.10 × (волна−1) |
| Множитель опыта | 1 + 0.10 × (волна−1) |

## Сундуки и лут (`src/Enemies.gd`, `src/Item.gd`)

| Параметр | Значение |
|---|---|
| Гарантированных сундуков за волну | 1 финальный, в центре экрана (`BASE_CHESTS`) |
| Шанс сундука с врага | 15% (`CHEST_DROP_CHANCE`) |
| Содержимое сундука с врага | 1 случайный предмет, без выбора |
| Содержимое финального сундука | выбор 1 из 3, без повторов (`CHEST_CHOICES`) |
| Множитель бонусов по редкостям | ×1.0 / ×1.3 / ×1.6 / ×2.0 / ×2.5 / ×3.2 (`RARITY_MULT`, временные) |
| Веса редкостей на 1-й волне | 70 / 20 / 7 / 2.2 / 0.7 / 0.1 (`RARITY_BASE_WEIGHTS`, временные) |
| Рост весов с волной | вес редкости t умножается на (1 + сдвиг)ᵗ; сдвиг = (волна−1) × 0.09 (`RARITY_WAVE_SHIFT`) |
| Бонус финального сундука | +0.8 к сдвигу (`RARITY_RICH_SHIFT`) |
