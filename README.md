# Хранитель Долины

2D-автобатлер на Godot 4.7, референс по механике — Overloot: герой дерётся сам,
игрок «дирижирует» через снаряжение и прокачку.

**Версия 0.3** — 20 волн, 6 редкостей предметов. Изометрический бой,
кликабельные сундуки, ускорение x2. Графика — цветные примитивы,
вся логика (включая интерфейс) написана кодом на GDScript.

## Как запустить

1. Открой Godot 4.7 → «Импорт» → выбери файл `project.godot` из этой папки.
2. Нажми F5 (или кнопку ▶) — запустится главная сцена.

## Что уже есть (объём v0.3)

- 1 локация из 20 волн с паузами между ними, 20-я волна — босс «Каменный страж»
- Бой в изометрии: земля ромбами, фон с небом и холмами (позже фон будет зависеть от уровня)
- Герой стоит слева, враги строем справа — строй зависит от числа врагов (1–5)
- Герой сам выбирает случайную цель и бьёт её, пока та не падёт, затем — следующую
- В волне не больше 5 врагов; чем дальше, тем чаще волки и големы вместо слизней
- Сундуки лежат на поле боя и открываются кликом; лагерь — только после сбора всех
- Сундук с врага: 1 случайный предмет; финальный сундук волны: выбор 1 из 3, награды реже
- 6 редкостей: Обычный, Необычный, Редкий, Мистический, Легендарный, Артефакт
- Чем выше волна, тем выше шанс выпадения редкого снаряжения
- Ускорение боя: кнопка x1 / x2
- 5 характеристик: Здоровье, Сила атаки, Защита, Скорость атаки, Регенерация (HP/с, работает в бою)
- Опыт и уровни: +2 очка характеристик за уровень, лечение 30% от макс. HP
- 5 слотов экипировки (оружие, броня, амулет, 2 кольца), 14 предметов
- Здоровье переносится между волнами: передышка лечит фиксированные +25 HP (не полностью)
- Полное восстановление — только после смерти или победы над боссом
- Экран снаряжения, экраны победы и поражения
- Мягкое поражение: лут и опыт сохраняются, волна просто начинается заново
- После победы над боссом — «новый заход»: враги сильнее, прогресс героя сохраняется

## Структура проекта

| Файл | Что делает |
|---|---|
| `Main.tscn` | Точка входа (единственная сцена, пустая — всё строится кодом) |
| `src/Main.gd` | Корневой узел: хранит состояние забега, переключает экраны |
| `src/Hero.gd` | Данные героя: характеристики, уровень, опыт, экипировка, рюкзак |
| `src/Item.gd` | Предметы: шаблоны, редкость, генерация лута |
| `src/Enemies.gd` | Типы врагов, состав волн, масштабирование сложности |
| `src/Actor.gd` | Боец на экране боя: рисование, полоса HP, таймер атаки |
| `src/BattleScreen.gd` | Экран боя: маршрут, враги, сундуки, всплывающий лут |
| `src/GearScreen.gd` | Экран снаряжения: статы, слоты, рюкзак, кнопка «В путь» |
| `tests/TestRunner.gd` | Автотесты (см. ниже) |

## Тесты

```bash
godot --headless --path . -s res://tests/TestRunner.gd
```

Проверяют генерацию предметов, прокачку, состав волн и прогоняют
полную симуляцию боя первой волны. Код выхода 0 — всё зелёное.
